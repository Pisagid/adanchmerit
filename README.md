# Adanch Merit Consulting — website

EB-2 National Interest Waiver green card support for Nigerian and African professionals.

Single static page, no build step:

```
index.html     the whole site (styles and script included, logo embedded)
media/         4 explainer videos, their poster frames, site icon, share image
.nojekyll      serve files as-is on GitHub Pages
```

Hosted with GitHub Pages from the `main` branch root. To use a custom domain (e.g. adanchmerit.com), add a `CNAME` file containing the domain and point the domain's DNS at GitHub Pages.
